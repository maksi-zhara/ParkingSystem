# Система управления и бронирования парковочных мест — итерация I0

Артефакты первой (подготовительной) итерации проекта.

- **Период итерации:** 07.09.2026 – 18.09.2026 (10 рабочих дней), ёмкость 60 чел.-ч.
- **Цель итерации:** зафиксировать и письменно согласовать с заказчиком правила ядра
  системы (роли, доступ, габариты, расписание, запрет пересекающихся броней)
  и архитектурный подход.
- **Особенность I0:** рабочий функционал в итерации не создаётся. Из историй бэклога
  берётся их аналитическая и проектная часть: фиксация правил, ролей, критериев
  приёмки и архитектурного подхода.
- **Демонстрация заказчику:** сценарии запрета конфликтующих броней, спецификация
  ролей и ограничений, архитектурная схема.
