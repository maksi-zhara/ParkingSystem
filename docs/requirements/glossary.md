# Глоссарий

Пакет ИСР: **A1**. Термины и сокращения, принятые в проекте.

| Термин | Определение |
| --- | --- |
| Парковка (parking lot) | Объект, содержащий одно или несколько парковочных мест и имеющий правила доступа и эксплуатации. |
| Уровень парковки (parking level) | Составная часть парковки (наземный, подземный, многоуровневый). |
| Парковочное место (parking spot) | Отдельный ресурс парковки, доступный для бронирования при соблюдении условий. |
| Бронирование (reservation) | Зафиксированное системой право пользователя на выбранное место в определённый период. |
| Транспортное средство (ТС) | Автомобиль пользователя, зарегистрированный с указанием габаритов. |
| Водитель / пользователь | Авторизованный пользователь, которому предоставлен доступ к системе и парковке. |
| Администратор парковки | Пользователь с полномочиями по управлению парковкой, местами, доступом и параметрами работы. |
| Специальное бронирование | Бронь, создаваемая администратором по согласованным условиям для служебных задач. |
| Рабочее расписание | Время работы парковки, в пределах которого допустимо бронирование. |
| Пересечение интервалов | Наличие общей ненулевой длительности у двух интервалов бронирования. |
| Статус `RESERVED` | Активная бронь, занимающая место. |
| Статус `CANCELLED` | Бронь, отменённая пользователем или администратором. |
| Статус `COMPLETED` | Бронь, период которой завершён и был использован. |
| Статус `EXPIRED` | Бронь, период которой истёк; место не занято. |
| JWT | Токен доступа, подтверждающий аутентификацию пользователя. |
| API | Программный интерфейс взаимодействия между компонентами системы. |
| Backend | Серверная часть приложения: бизнес-правила, права доступа и данные. |
| Frontend | Пользовательская часть веб-приложения. |
| QA | Специалист по обеспечению качества, тестированию и участию в приёмке. |
| ИСР | Иерархическая структура работ (декомпозиция проекта на пакеты работ). |
| SP | Story Points — относительная оценка сложности истории. |
| DoR / DoD | Definition of Ready / Definition of Done — критерии готовности истории к работе и к приёмке. |
